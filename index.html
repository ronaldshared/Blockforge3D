BLOCKFORGE 3D

Construcción libre, fauna voxel y terreno por regiones.

Instrucciones y controles

Tablet

  1. Utiliza el tablet en posición horizontal.
  2. Presiona Nueva partida para generar un mundo o Continuar para cargar el último guardado.
  3. Mueve el joystick grande del lado izquierdo para caminar. Llévalo al borde para correr.
  4. Desliza un dedo por el lado derecho de la pantalla para mirar alrededor y apuntar con la cruz central.
  5. Mantén presionado − para retirar bloques o ＋ para colocarlos.
  6. Usa ▲ para saltar o subir, ▼ para bajar, Volar para activar el vuelo y Bloque para cambiar el material.
  7. Presiona II para pausar. Desde la pausa puedes continuar, guardar o volver al menú.

Computador

WASD mover · Espacio saltar/subir · Ctrl bajar · Shift correr · Clic izquierdo retirar · Clic derecho colocar · 1-8/rueda seleccionar · F volar · R volver · T cambiar hora · Esc pausa.
